# Proposal

## Why

Установка Windows-агента сейчас требует трёх сущностей: бинарника, `install.ps1` (копирование в `%ProgramFiles%\siren`, конфиг из шаблона, служба, firewall-правило) и правки конфига. При этом установка через панель пульта — без скрипта — оставляет агент неполноценным: без firewall-правила ловушки недостижимы с других машин, а служба ссылается на exe там, где его случайно запустили (например, в Downloads). Хочется распределение «один файл»: скачать `siren.exe`, запустить — всё необходимое создаётся само.

## What Changes

- Первый интерактивный запуск exe (служба не установлена) выполняет самоустановку: копирует себя в `%ProgramFiles%\siren\siren.exe`, создаёт `config.json` из встроенного шаблона (`agent_name` из hostname, токен-плейсхолдер), перезапускается оттуда, устанавливает службу (автостарт, LocalSystem) и открывает панель; служба не запускается, пока в конфиге токен-плейсхолдер (существующая конвенция).
- Firewall-правило «siren traps» (входящий TCP к exe) переносится из `install.ps1` в установку службы: создаётся при `-service install` и установке из панели, удаляется при удалении службы; повторная установка не дублирует правило.
- Повторный запуск нового exe при установленной службе работает как обновление: служба останавливается, exe в `%ProgramFiles%\siren` заменяется, служба возвращается в прежнее состояние.
- Windows-кит (`dist/siren-win-kit`) сжимается до одного exe; `install.ps1` и `uninstall.ps1` удаляются из репозитория. Linux-кит и `install.sh` не меняются.
- Документация (README, `docs/deployment.md`) — новый раздел установки Windows: один exe, без Go и скриптов.

## Capabilities

### New Capabilities

- `win-agent-setup`: жизненный цикл установки агента на Windows — самоустановка при первом запуске (self-copy, бутстрап конфига, служба, firewall-правило), обновление повторным запуском, идемпотентность.

### Modified Capabilities

- `win-control-ui`: «Управление службой из формы» — установка службы из панели включает создание firewall-правила, удаление службы убирает его.

## Impact

- `cmd/siren` (Windows): первый запуск, self-copy, встроенный шаблон конфига, firewall при install/remove службы, поведение панели.
- `dist/siren-win-kit/`: состав (только exe); `deploy/`: минус два ps1.
- Дока: README, `docs/deployment.md`.
- Linux-код и кит, конфиг-формат, конвейер агента — без изменений.
