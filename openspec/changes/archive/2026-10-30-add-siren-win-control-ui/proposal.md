# Proposal

## Why

Развёртывание агента на Windows-машине сейчас требует elevated-сессии, правки JSON и запоминания CLI-флагов (`-service install` и т.д.). Для массового «скопировал на машину — настроил — забыл» нужна локальная форма управления: галочки ловушек, кнопки службы и поля настроек в одном окне.

## What Changes

- Новый режим агента `siren.exe`: при интерактивном запуске (двойной клик) агент работает как сейчас (ловушки + датчики), плюс появляется иконка в трее; консольное окно при этом скрывается (при запуске из терминала консоль остаётся).
- Трей-иконка: открытие окна управления, быстрые действия службы, выход.
- Повторный запуск exe не плодит процессы: второй экземпляр сигнализирует первому открыть окно и завершается (named mutex + сигнал).
- Окно управления (native, от администратора — manifest `requireAdministrator`):
  - управление службой: установить+запустить / стоп / удалить, текущий статус SCM;
  - редактор ловушек: чекбоксы портов профиля + добавление своих портов (порт, эмулятор, TLS) и отключение отдельных ловушек;
  - настройки: Telegram (token, chat_id), окно агрегации, allowlist, уровень лога;
  - сохранение конфига (`config.Save` рядом с exe) с валидацией и перезапуском службы для применения.
- Живой мониторинг событий в окне НЕ входит: наблюдение остаётся в Telegram.
- Существующие CLI-режимы (`-service …`, консольный запуск) сохраняются без изменений.

## Capabilities

### New Capabilities
- `win-control-ui`: локальная форма управления агентом на Windows — запуск режима UI (трей, одиночный экземпляр), управление службой Windows и редактирование настроек агента через форму.

## Impact

- Код: `cmd/siren/` — новые файлы UI (`ui_windows.go`, трей, single-instance; build tag windows), `config.Save` в `internal/config`; сборка с embedded manifest (rsrc) для requireAdministrator.
- Зависимости: `lxn/walk` + `lxn/win` (pure Go, без cgo, windows-only) — первое отступление от «только официальные библиотеки», осознанное (см. design).
- Сборка: exe становится GUI-подсистемой Windows (консольное окно прячется программно для терминального запуска); кросс-сборка Linux не затрагивается.
- Развёртывание: kit для Windows дополняется — install.ps1 остаётся, но ручной путь теперь «скопировать и запустить exe».
