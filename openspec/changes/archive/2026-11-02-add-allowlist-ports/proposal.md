# Proposal

## Why

Allowlist сейчас глушит все события источника целиком: чтобы разрешить хосту легитимно ходить по SSH, приходится разрешать ему всё — и его стучание на другие ловушки тоже остаётся невидимым. Нужен точечный allow: «этому хосту разрешён только ssh», а всё остальное от него — тревога.

## What Changes

- Записи allowlist получают необязательный суффикс портов: `192.168.1.10` — все порты (как раньше), `192.168.1.10:22` — только порт 22, `10.0.0.0/24:22,3389` — сеть и список портов. Для IPv6 с портами — скобочная форма `[::1]:22`.
- Запись с портами глушит только события, привязанные к этим портам: подключения к ловушкам на этих портах и события реальных входов соответствующего сервиса (SSH → 22, RDP → 3389). События без порта и события других портов от того же хоста остаются видимыми.
- Датчики входов (doors) проставляют событиям сервисный порт: SSH-факты — 22, RDP-факты — 3389. Сегодня у этих событий порт не заполнен, поэтому точечный allow на них не действует.
- Валидация конфига принимает новый синтаксис (включая скобочную IPv6-форму); невалидные записи отклоняются как прежде.
- Поле allowlist в панели пульта обновляет подсказку (формат с портами); чтение, парсинг и сохранение используют общий с конфигом валидатор.
- README дистрибутивов описывают формат записей с портами.

Обратно совместимость: старые записи без портов читаются и работают как раньше (**BREAKING** нет).

## Capabilities

### New Capabilities

(нет — точечное разрешение встраивается в существующую способность доводки событий)

### Modified Capabilities

- `alert-delivery`: новое требование «Точечное разрешение источников» — семантика allowlist-записей с портами: подавляются только события разрешённых портов, остальное от источника доставляется как прежде.
- `win-control-ui`: требование о настройках — поле allowlist принимает записи с необязательным списком портов, подсказка и валидация отражают новый формат.

## Impact

- `internal/config` — валидация allowlist-записей (синтаксис `хост[/CIDR][:порты]`), тип хранения (запись с выделенным списком портов).
- `cmd/siren/runtime.go` — `allowlist`: хранение портов у записи, `match` с портом события.
- `cmd/siren/pump` (`pumpEnrich`) — передача `DstPort` в матчер.
- `internal/doors` — штамп сервисного порта (22/3389) в событиях входов.
- `cmd/siren/ui_windows.go` — подсказка поля allowlist.
- `dist/*/README.txt` — описание формата.
