# Tasks

## 1. Парсер формата allowlist-записи

- [x] 1.1 В `internal/config` — `ParseAllowlistEntry` (D4): сначала цельная строка как IP/CIDR (старое поведение, порты = все); при промахе — разбор суффикса по последнему `:` (хвост — список чисел 1–65535 через запятую, голова — IP/CIDR; IPv6 только в скобках `[::1]:22`). Ошибка — с текстом «not an IP, CIDR or host:ports entry». Тесты: `192.168.1.10`, `10.0.0.0/24`, `192.168.1.10:22`, `10.0.0.0/24:22,3389`, `[::1]:22`, `::1` (адрес, без портов), мусор (`not-an-ip`, `192.168.1.10:`, `192.168.1.10:0`, `192.168.1.10:70000`, `192.168.1.10:22,abc`), неоднозначный `fe80::1:22` (остаётся IPv6-адресом)
- [x] 1.2 Валидация конфига (`config.go`) — allowlist-записи через `ParseAllowlistEntry`, текст ошибки сохраняет стиль с номером записи (`config: allowlist[i]: ...`); хранение — записи не теряют портов при загрузке/сохранении конфига (round-trip). Тесты: старый конфиг с `allowlist: ["192.168.1.10", "10.0.0.0/24"]` загружается как раньше; запись с портами проходит валидацию и сохраняется в файл без изменений; `not-an-ip` и `192.168.1.10:0` отклоняются

## 2. Матчер с портами

- [x] 2.1 `cmd/siren/runtime.go` — `newAllowlist` строится из валидированных записей (строка + порты, D5); `allowlist.match(ip, port)`: запись без портов матчит любой порт, запись с портами — только перечисленные; IP вне префикса и невалидный IP не матчатся. Тесты: запись без портов гасит порт 22 и порт 23; запись `:22` гасит 22, не гасит 23 и порт 0; сеть `/24` с портами гасит порт из списка у хоста из сети; мусорная запись (конфиг правлен на лету) не матчит ничего и логируется
- [x] 2.2 `pumpEnrich` передаёт `ev.DstPort` в матчер. Тесты: событие ловушки от разрешённого на «:22» хоста на порт 22 гасится, на порт 23 — проходит; событие входа с портом 0 от того же хоста проходит

## 3. Сервисные порты датчиков входов

- [x] 3.1 `internal/doors` — события входов штампуют `DstPort`: RDP-факты (4624/4625, RemoteConnectionManager) — 3389, SSH-факты (journald) — 22 (D3). Тесты: фикстуры 4624/4625 и journald дают события с портами 3389/22; событие без IP сохраняет порт
- [x] 3.2 Сквозной тест семантики: allowlist «хост:22» + SSH-факт от хоста → гасится; RDP-факт от того же хоста (порт 3389) → проходит. Тест на уровне `pumpEnrich` с фейковым источником дверей (проверка integration-склейки 2.2 и 3.1)
