# Proposal

## Why

Проект готов к эксплуатации (два живых агента), но у него нет публичного лица: нет git-репозитория, `.gitignore` и систематизированной документации. Установка и параметры сейчас описаны только в `README.txt` внутри сборочных китов (`dist/`), которые не хранятся в git и пересобираются, а живой каталог `agent/` содержит секреты (токен Telegram, ключ ловушки), которые нельзя публиковать. Выложить проект в GitHub публично — значит получить историю изменений, безопасную публикацию и документацию, не зависящую от локальных артефактов.

## What Changes

- Добавить `.gitignore`: `agent/` (целиком — секреты, логи, бинарники), `bin/`, `dist/` (сборочные артефакты), журналы; личные конфиги OpenCode (`opencode.json`, `AGENTS.md`, `.opencode/`) в репозиторий не включаются.
- Добавить `LICENSE` (MIT, 2026).
- Добавить `README.md` — обзор проекта, краткое описание работы, быстрый старт для обеих платформ, ссылки на `docs/`.
- Добавить `docs/`:
  - `docs/architecture.md` — конвейер (ловушки и датчики входов → обогащение → агрегация → Telegram), сторож здоровья, семантика allowlist;
  - `docs/configuration.md` — все параметры `config.json` с примерами;
  - `docs/deployment.md` — установка Windows (кит, пульт, служба) и Linux (`install.sh`, systemd), проверка ловушек, текстовые примеры алертов.
- Инициализировать git-репозиторий (первый коммит) и опубликовать на `https://github.com/kur890440-ops/siren`.

Источники содержимого: `dist/*/README.txt`, `deploy/`, main-спеки `openspec/specs/`. Из живого каталога `agent/` в документацию не переносится ничего.
