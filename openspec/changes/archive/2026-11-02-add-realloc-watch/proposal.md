# Proposal: add-realloc-watch

## Why

SMART-счётчики секторов (realloc/pending) — главный ранний признак деградации диска. На Linux агент их показывает (smartctl: «sda: ok — realloc 481, pending 0»), на Windows — нет: коллектор L1 читает WMI `MSFT_PhysicalDisk`, который отдаёт только HealthStatus, поэтому панель и отчёты показывают голое «ok» без цифр. При этом на сервере уже виден диск с realloc 481 — а растущий realloc при статусе «ok» (SMART ещё PASSED) проходит молча: тревога срабатывает только на смену статуса.

## What Changes

- Windows-коллектор L1 дополняется счётчиками SMART: realloc (атрибут 5) и pending (атрибут 197) читаются из WMI `root\wmi\MSStorageDriver_FailurePredictData` (парсинг таблицы 30×12 байт) и вливаются в существующие записи `L1Disk` по совпадению диска (PNPDeviceID/InstanceName, резерв — модель). Рендеры (панель, отчёты) уже печатают «— realloc N, pending N» — им изменений не нужно.
- Диф-проверка сторожа пополняется новым видом изменения: рост счётчика реальных секторов между снимками (realloc). Рост на 1 и более — тревога в Telegram немедленно, даже если статус диска остаётся «ok». Работает на обеих платформах (источник счётчиков не важен).
- Если счётчики недоступны для диска (USB-мост, NVMe через WMI-класс ATA, контроллер без прокидывания SMART) — диск показывается как раньше, без цифр и без фиктивных ошибок.

## Capabilities

### New Capabilities

(нет)

### Modified Capabilities

- `disk-health-watch`: собранные счётчики realloc/pending включаются в снимок L1 на всех платформах, где они доступны; изменение счётчиков между снимками порождает немедленную тревогу независимо от статуса SMART.

## Impact

- `internal/health/disks_windows.go` — новый WMI-SMART источник/обогащение `physicalDiskSource`; парсер таблицы атрибутов (кроссплатформенный, тестируемый).
- `internal/health/diff.go` — новый вид изменения «рост realloc» (+ тесты).
- `internal/health/runner.go` — формат сообщения тревоги.
- Спека `openspec/specs/disk-health-watch/spec.md` — 2 ADDED-требования через дельту.
- Панель и Telegram-рендеры — без изменений (поддержка уже есть).
